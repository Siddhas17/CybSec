## Manual analyst notes (not produced by the automated script above)

These required direct inspection of raw file bytes beyond what the generic
inspector checks, added 2026-08-18:

- **`Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv` has 288,602
  fully-blank trailing rows** (every one of the 85 fields empty, CRLF line
  endings) — 63% of the file's 458,968 data rows. Verified this is a
  genuine artifact of this `GeneratedLabelledFlows` distribution, not a
  parsing bug: the Phase 1 `MachineLearningCSV` version of the exact same
  file has exactly 170,366 data rows with zero blank rows — the same real
  row count as `458,968 - 288,602 = 170,366` here. The automated
  "duplicate rows" and "missing values" figures for this file above are
  inflated by this padding (all 288,602 blank rows are mutually
  "duplicate" and "missing" on every column, including the required
  topology fields). **These rows must be dropped before any graph
  construction** — do not treat this file's raw row/duplicate counts at
  face value.
- **Timestamps are day-first** (`D/M/YYYY H:MM[:SS]`), confirmed by
  cross-referencing known capture days against the dates: Monday file
  shows `03/07/2017` (3 July = Monday), Wednesday shows `5/7/2017` (5 July
  = Wednesday), etc. — if parsed as month-first this would silently
  misinterpret every day-of-month <= 12. Format is also **inconsistent
  between files**: Monday uses zero-padded `03/07/2017 08:55:58` (with
  seconds), Wednesday uses unpadded `5/7/2017 8:42` (no seconds). Any
  timestamp parsing must pass `dayfirst=True` and tolerate both forms
  (e.g. pandas `format="mixed", dayfirst=True`).
- **Protocol column contains exactly 3 distinct values across all 8
  files: `0`, `6`, `17`** — TCP (6) and UDP (17) as expected, plus `0`
  (used here for flows CICFlowMeter could not attribute to TCP/UDP, e.g.
  ICMP/other). No unexpected/out-of-range protocol numbers found anywhere
  in real data rows (the "unexpected protocol" flag in the WebAttacks
  file below fires only on the blank-row artifact's NaNs, not real data).
- **Label mojibake matches the Phase 1 finding exactly**: the three "Web
  Attack" labels in `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv`
  contain the same U+FFFD replacement character (`Web Attack � Brute
  Force`, `� Sql Injection`, `� XSS`) as the Phase 1 dataset. The same
  prefix-matching normalization in `ml/preprocessing/labels.py` should
  apply unchanged.
- **`Fwd Header Length` / `Fwd Header Length.1` duplicate-column quirk
  reproduces here too** (columns 41 and 62), matching the Phase 1 finding
  — same artifact of the original CICFlowMeter header, not new.
- Row-count reconciliation: topology dataset totals 3,119,345 raw data
  rows across 8 files vs. Phase 1's 2,830,743 — the entire 288,602
  difference is fully explained by the WebAttacks blank-row artifact
  above; every other file's row count matches Phase 1 exactly on
  spot-check. No evidence of missing or extra real flow records between
  the two distributions.
